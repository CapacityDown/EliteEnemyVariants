# Elite Enemy Variants

【HostOnlyMOD】Enhances enemy behavior and abilities with host-only installation.

【HostOnlyMOD】ホストのみの導入で、敵の挙動や能力を強化します。

Enemies can become Enhanced, gaining abilities that build on their own distinctive behavior. Only the host needs the mod for gameplay effects; unmodded participants are supported.

敵が確率でEnhanced個体になり、それぞれの固有ギミックを活かした強化を受けます。バニラ参加者にも適用されます。

## Elites

Open **Elites** in the lobby or pause menu to browse enhancement descriptions, change per-enemy selection as the host, refresh display data, or prepare a bug report. With RoleShuffle or Stage Flux installed, Elites appears beneath their buttons.

ロビーやポーズメニューの **Elites** から強化説明を閲覧できます。ホストは敵ごとのON/OFFを切り替えられます。表示データの再取得や不具合レポートの作成にも対応します。RoleShuffleやStage Fluxと併用する場合は、それらのボタンより下に配置されます。

See the [player guide](package/README.md) for installation, enemy behavior, and settings.

導入方法・敵ごとの強化内容・設定は[プレイヤーガイド](package/README.md)をご覧ください。

## Questions and bug reports / ご質問・不具合報告

Use [GitHub Issues](https://github.com/CapacityDown/EliteEnemyVariants/issues). Please include what happened, reproduction steps, and the expected result. You can prepare a report from **Elites > Tools > Report a Problem**. Review it before posting; nothing is uploaded automatically. A GitHub account is required.

[GitHub Issues](https://github.com/CapacityDown/EliteEnemyVariants/issues)に、発生した問題・再現手順・期待した結果を記載してください。**Elites > Tools > Report a Problem** からレポートを準備できます。自動送信はしないため、内容を確認してから投稿してください。GitHubアカウントが必要です。
